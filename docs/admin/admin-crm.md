# Admin CRM

## Purpose

Give staff a clear view of users, institutions, content, payments, support, and
system activity.

## Main Views

- User search and profile
- Student/teacher/institution accounts
- Subscription and payment status
- Support tickets
- Content status
- Simulation status
- Staff activity
- Audit logs

## Admin Actions

- Disable/restore account
- Reset device/session lock
- Manage subscription status
- Add internal note
- Assign ticket
- View content review history
- Roll back published content version

## Dashboard Widgets

- Active users.
- Paid users.
- Institutions.
- Seats used.
- Open support tickets.
- Content waiting for review.
- Simulations with failed validation.
- Recent publish activity.
- Payment issues.

## User Profile View

Must show:

- Account status.
- Roles and permissions.
- Subscription/access.
- Institution membership.
- Active sessions/device lock.
- Progress summary.
- Support tickets.
- Admin notes.
- Audit events.

## Content Overview

Must show:

- Drafts.
- In review.
- Published.
- Needs revision.
- Missing translations.
- Recently changed simulations.
