# Content Workflow

## States

Idea -> researching -> draft -> simulation design -> math review -> curriculum
review -> language review -> QA preview -> ready to publish -> published ->
needs revision -> archived.

## Required Metadata

- Owner
- Reviewer
- Class, subject, chapter, concept
- Source references
- Version
- Last updated date
- Accuracy notes
- Known limitations

## Publishing Rule

Do not publish a simulation or formula without source reference, R&D approval,
and preview validation.

## Review Responsibilities

Content editor:

- Draft title, objective, explanation, hints, and practice text.

Simulation designer:

- Configure template, variables, outputs, visuals, presets, and preview.

R&D reviewer:

- Approve formula correctness, units, assumptions, and scientific explanation.

Language reviewer:

- Approve English/Bangla wording where required.

Admin:

- Publish, unpublish, rollback, and manage priority.

## Revision Rule

Published content is not edited directly. Changes create a new draft version.
Rollback should restore a previous published version without deleting history.
