# Curriculum Map

## Hierarchy

Class -> Subject -> Paper -> Chapter -> Concept -> Simulation -> Formula ->
Practice question.

## Class 9-10

- Physics
- Chemistry
- Mathematics
- Higher Mathematics
- Biology

## Class 11-12

- Physics 1st Paper
- Physics 2nd Paper
- Chemistry 1st Paper
- Chemistry 2nd Paper
- Higher Mathematics 1st Paper
- Higher Mathematics 2nd Paper
- Biology 1st Paper
- Biology 2nd Paper

## Source Rule

Use Markdown chapter files as the primary analysis source. Future clean English
PDFs should be converted to Markdown before simulation planning.

## Catalog Shape

Every catalog record should support:

- Stable slug.
- English title.
- Bangla title when available.
- Sort order.
- Active/draft status.
- Source references.
- Free/pro/institution access visibility.

Each concept should eventually include:

- Learning objective.
- Formula list.
- Simulation list.
- Practice question list.
- Common mistake notes.
- Source pages or chapter references.
- Admin review state.
