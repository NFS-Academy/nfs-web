## Rules For Future Codex Sessions

- Do not create app code from this folder alone; create an implementation plan first.
- Use the current default stack unless a later decision document changes it.
- Keep frontend and backend separated through APIs.
- Treat admin simulation creation as a safe template/module workflow, not a
  free-form production code editor for non-technical users.
