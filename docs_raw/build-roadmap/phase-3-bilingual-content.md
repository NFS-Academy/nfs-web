# Phase 3: Bilingual Content

## Goal

Make English and Bangla content production reliable.

## Outputs

- Localization data model
- Language toggle
- Admin translation fields
- Missing translation indicators
- Language review workflow

## Exit Criteria

Core student flows can show English and Bangla content without hardcoded text.

reviewed. Do not block technical simulation development on full Bangla coverage.
