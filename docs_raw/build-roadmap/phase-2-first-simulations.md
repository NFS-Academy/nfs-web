# Phase 2: First Simulations

## Goal

Build the first high-quality simulation set.

## Outputs

- Chemistry MVP simulations
- Physics Chapter 3 first simulations
- Formula panels
- Unit conversion helpers
- Practice mode
- Progress tracking
- Simulation QA checklist

## Exit Criteria

At least three simulations are polished enough to prove the learning loop.

## First Build Order

1. Acid-base neutralization.
2. Precipitation reaction.
3. Momentum Lab.
4. Newton's Second Law Lab.
5. Collision Cart Lab.

## Required Shared Pieces

- Formula cards.
- Unit conversion helper.
- Variable controls.
- Output metric cards.
- Practice tab.
- Progress callbacks.
- Simulation reset.

## QA Gate

Each simulation needs at least one hand-checked example and one board-style
practice question.
