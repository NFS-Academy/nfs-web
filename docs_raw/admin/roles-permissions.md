# Roles And Permissions

## Public Roles

- Guest
- Registered student
- Paid student
- Teacher
- Institution owner
- Institution admin
- Institution student

## Staff Roles

- Support agent
- Finance manager
- Content editor
- Simulation designer
- R&D reviewer
- Admin
- Super admin

## Permission Principles

- Students access learning content based on plan.
- Teachers assign and view student progress only for their groups.
- Institution admins manage their own seats and users.
- Editors draft content but cannot publish without review.
- R&D reviewers approve science and math accuracy.
- Admins publish, rollback, and manage users.
- Super admins manage staff permissions and system settings.

## Permission Matrix

Guest:

- View public pages and sample content.

Student:

- View allowed learning content.
- Save own progress.
- Manage own profile and active session.

Teacher:

- Use presentation mode.
- Assign content to own groups.
- View progress for assigned students.

Institution admin:

- Manage organization members.
- Manage seats and invites.
- View organization reports.

Content editor:

- Create and edit drafts.
- Submit content for review.

Simulation designer:

- Configure simulations.
- Run previews and validations.

R&D reviewer:

- Approve or reject scientific/math accuracy.

Admin:

- Publish content.
- Manage users.
- Reset device locks.
- View audit logs.

Super admin:

- Manage staff roles.
- Manage system settings.
