# Class 11-12 Plan

## Subjects And Papers

- Physics 1st Paper
- Physics 2nd Paper
- Chemistry 1st Paper
- Chemistry 2nd Paper
- Higher Mathematics 1st Paper
- Higher Mathematics 2nd Paper
- Biology 1st Paper
- Biology 2nd Paper

## Planning Rule

Class 11-12 content should not be built until the MVP learning loop and content
workflow are proven with Class 9-10. Keep this structure ready for expansion.

## Expected Needs

- More advanced formula handling
- More graphs and derivations
- More complex lab simulations
- Stronger teacher and exam-prep workflows

## Expansion Strategy

Do not start Class 11-12 implementation until Class 9-10 proves:

- Catalog structure.
- Simulation workspace.
- Formula engine.
- Practice mode.
- Admin review and publishing.
- Basic access control.

When Class 11-12 begins, create paper-specific chapter maps before adding
simulations. This avoids mixing first-paper and second-paper concepts.

## Future Simulation Types

- Advanced graph labs.
- Derivation steppers.
- Circuit and electricity labs.
- Organic/inorganic reaction labs.
- Calculus and vector visualizers.
- Biology process and diagram labs.
